# Security policy

## Reporting a problem

Please report security problems privately, not in a public issue:
https://github.com/RayanBayat/wow-coach/security/advisories/new

Include what you found, how to see it happen, and which version you used. You will get an
answer as soon as possible, and a fix will be released before the problem is described in
public.

## Problems that affect Sign in with ChatGPT

wow-coach uses OpenAI's "Sign in with ChatGPT". OpenAI's terms ask apps to report
vulnerabilities or breaches that affect users to OpenAI promptly. When a problem could expose
a player's ChatGPT sign-in, it is also reported to OpenAI, and players are told what to do (for
example: sign out and disconnect wow-coach in their ChatGPT settings).

## Supported versions

Only the newest release gets fixes.
